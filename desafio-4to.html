¿Qué quiere decir cada palabra del código de la placa?
void setup() { … }Lo que está entre las llaves pasa una sola vez, cuando se prende la placa. void quiere decir que esa parte hace cosas pero no devuelve ningún resultado.
void loop() { … }Lo que está entre las llaves se repite para siempre, de arriba hacia abajo, mientras la placa tenga energía.
{ }Las llaves marcan dónde empieza y dónde termina un bloque: lo que va adentro de setup, de loop o de un if.
;El punto y coma termina cada orden, como el punto al final de una oración.
// …Un comentario: la placa lo ignora. Es una nota para las personas que leen el código.
intUna variable que guarda un número entero: 0, 153, 1023.
floatUna variable que guarda un número con coma: 24.78. En el código la coma se escribe con punto.
int lectura = …Crea una variable llamada lectura y le guarda un valor. El nombre lo elige quien programa.
= y ==Un igual guarda: alerta = 1. Dos iguales preguntan: alerta == 1 es «¿alerta vale 1?».
< > <= >=Menor, mayor, menor o igual, mayor o igual.
&&Quiere decir y: las dos condiciones se tienen que cumplir.
if (…) { … } else { … }Si se cumple la condición, hace lo primero. Si no, hace lo del else.
pinMode(13, OUTPUT)Le dice a la placa que por el pin 13 va a mandar corriente, porque ahí hay un LED.
digitalWrite(13, HIGH)Prende el pin 13. Con LOW lo apaga. También se puede usar 1 y 0.
analogRead(A0)Lee el sensor que está en el pin A0 y devuelve un número de 0 a 1023.
Serial.begin(9600)Abre la conversación con la compu, para poder escribir en el monitor serie.
Serial.print / printlnEscriben en el monitor. print sigue en el mismo renglón. println escribe y baja.
delay(1000)Espera. Cuenta en milésimas de segundo: 1000 es un segundo.
millis()Cuántas milésimas pasaron desde que arrancó la placa. Es un cronómetro.

¿Cómo sabemos después si el aparato decidió bien? Que anote en una tabla cada medición y cada decisión.

¿Qué es esta tabla?

Cada renglón es una medición y una decisión: en qué segundo, cuánto midió y si avisó (1) o no (0).

Con esa tabla se puede revisar después si el aparato decidió bien: ¿avisó cuando tenía que avisar? ¿Avisó de más?

// Aviso de helada · versión con tabla (tiene dos errores)

float anterior = 100;          // va AFUERA del loop: así se acuerda de la medición anterior

void loop() {

      Sensor nuevo · la luz

      Las heladas fuertes son de noche. ¿Y si el aparato supiera si es de día?

      Cómo se conecta el fotorresistor

      Buscalo en Tinkercad como Fotorresistor. Una pata a 5V. La otra pata a A1, y desde esa misma pata una resistencia de 10 kΩ a GND.

      Las estaciones reales miden la radiación solar con un sensor parecido, pero más preciso.

      1. Copiá este código en Tinkercad. Ahora la tabla tiene una columna más: luz.
      // Estación · temperatura y luz
float anterior = 100;

void setup() {
  Serial.begin(9600);
  pinMode(13, OUTPUT);
  Serial.println("segundos,grados,luz,alerta");   // los títulos, una sola vez
}

void loop() {
  int lectura = analogRead(A0);
  float grados = (lectura * 5.0 / 1023 - 0.5) * 100;
  int luz = analogRead(A1);          // el fotorresistor: con más luz, el número sube

  int alerta = 0;
  if (grados < 3 && grados < anterior) {   // ← sumale: «y es de noche»
    alerta = 1;
  }
  digitalWrite(13, alerta);
  anterior = grados;

  Serial.print(millis() / 1000);
  Serial.print(",");
  Serial.print(grados);
  Serial.print(",");
  Serial.print(luz);
  Serial.print(",");
  Serial.println(alerta);
  delay(1000);
}

      // Riego · humedad y luz
int avisando = 0;

void setup() {
  Serial.begin(9600);
  pinMode(13, OUTPUT);
  Serial.println("segundos,humedad,luz,avisando");   // los títulos, una sola vez
}

void loop() {
  int humedad = analogRead(A0);
  int luz = analogRead(A1);          // el fotorresistor: con más luz, el número sube

  if (avisando == 0 && humedad < 200) {   // ← sumale: «y no es pleno sol»
    avisando = 1;
  }
  if (avisando == 1 && humedad > 250) {
    avisando = 0;
  }
  digitalWrite(13, avisando);

  Serial.print(millis() / 1000);
  Serial.print(",");
  Serial.print(humedad);
  Serial.print(",");
  Serial.print(luz);
  Serial.print(",");
  Serial.println(avisando);
  delay(1000);
}
